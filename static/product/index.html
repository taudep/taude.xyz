Mission control for the work you don't remember doing.

taude keeps track of AI coding sessions, browser tabs and the routine work agents do for you, across every machine you use. It runs on your own computer, writes plain markdown, and stays out of the way.

You stopped typing prompts. The agents didn't stop working. Someone should keep track.

It's driven from the keyboard. Press 1 to 5 here too.

Work: every agent session on every machine you use, and what each one left behind.

Know what every session did, and pick up where it stopped.

Run thirty agent sessions at once and the terminal tabs stop meaning anything. taude keeps the record instead.

  • A wrap-up for every session

    When a Claude Code, pi or opencode session ends, it records what was built, the artifacts it produced, and what the agent thinks is still left to do.

  • Git state at a glance

    Uncommitted changes, commits not yet pushed, PRs open or waiting to merge, and worktrees that are safe to clean up.

  • Reopen with one key

    Press enter on any session to open Ghostty in the right folder with the agent resumed and its memory intact.

  • Ask what to do next

    A side panel answers from your own records: past wrap-ups, open follow-ups, PR state and the plan behind the project. Use any model you like.

Who did all this? You did. Allegedly.

Close a hundred tabs without losing one.

Every evening, and every Friday afternoon, taude sweeps your Chrome and Firefox tabs into lists. Then it closes them. Pinned tabs stay put.

  • Sorted by what they ask of you

    Tickets and pages you were editing become to-dos. Pages you were only reading become follow-ups. Hacker News threads go to reading, story and comments as one item. YouTube goes to watch.

  • Nothing closes before it's saved

    The list is written and read back first. Every sweep keeps a record of what it closed, and one key reopens the lot.

  • Mark anything for later

    Press Option-M on any page to send it to your reading archive and personal wiki, with a note on why it caught your eye.

  • Prune in seconds

    Select a batch with the space bar, then send it to Obsidian, mark it done, or drop it. Old lists archive themselves after four weeks.

Too lazy to prompt, too horrified to look. We looked for you.

The routine work runs on a schedule.

Each workflow is a skill an agent can run, started by a key or by the clock. You see every run, and nothing public goes out without you.

  • Daily and weekly summaries

    A short note each evening. At the end of the week, a list of only what's still unfinished, and what you accomplished, project by project.

  • Shutdowns, archive processing, newsletters

    Daily and weekly shutdowns, turning your reading into wiki pages, drafting the weekly roundup. Add your own.

  • A review pile for anything public

    Blog posts, LinkedIn and X drafts wait for your approval. taude suggests them from what you actually shipped.

  • Quiet reminders

    Reminders are to-do items with a time. When one comes due you get one small notification, never a window in your way.

Apparently you built four things on Tuesday. Here's the receipt.

Your data is markdown in your own vault.

Plans, session logs, task lists and the handbook live in an Obsidian folder that syncs between your machines. Open any of it without the app.

  • Built for more than one machine

    Each machine writes only its own files, so sync never has to merge anything. The app reads them all and shows one picture.

  • One config file that explains itself

    Plain YAML with a comment on every setting. One section applies to every machine you use, and each one can override it, so tools you need on only one machine stay there.

  • Your skills, everywhere

    Shared skills from a public repo and private ones from your vault, installed into every agent on every machine.

  • Any ticket system

    One ticket view over whichever tracker each computer uses, whether that's Jira or Linear, with room for others.

Fast, local, and on the keyboard.

A Go backend in a lightweight native window for Mac, Windows and Linux. A small SQLite database on each machine keeps it quick. Nothing runs in the cloud, and the same keys work everywhere in the app.
